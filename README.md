# Anatomy Mastery Pro — Complete v1

## What is included
- Modular architecture
- Chapters 1–4 Notes
- Flashcards with shuffle, timer, colour rotation, completion result and resit
- Master Question Bank with shuffled question order + shuffled answer order
- Instant correct/incorrect feedback in practice
- Mistake Vault
- Short Answers with model-answer reveal
- 6 Quiz sets
- 5 Mock Exams with timed mode and full review after Submit
- Stream C schedule and task completion
- Progress / attempt history
- Local study-time and visit tracking
- Footer: Created by Mustafa Beigi + contact email

## Future updates
The site is intentionally modular. When a new chapter/quiz/schedule arrives, edit only the relevant data file:
- `data/chapters.js`
- `data/quizzes.js`
- `data/mocks.js`
- `data/schedule.js`

## Important privacy note
This static version does not record raw IP addresses. Study progress is stored only in the user's browser using localStorage.
A privacy-conscious anonymous analytics backend can be added later for cross-device visitor counts.
